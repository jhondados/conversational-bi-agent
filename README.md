> **Chat with your data warehouse**. Ask questions in Portuguese or English, get charts, tables and written insights automatically. **8,200 daily users**, **94% SQL accuracy**, eliminating analyst bottleneck.

## 💬 Example Interactions
```
User: "Quais produtos tiveram queda de vendas em São Paulo no último trimestre?"
Bot:  [Auto-generates SQL] [Executes on BigQuery] [Renders bar chart]
      "Os 5 produtos com maior queda foram: Produto A (-34%), Produto B (-28%)..."

User: "Por quê?"
Bot:  [Correlates with external data] "A queda coincide com a entrada de 3 concorrentes..."

User: "Mostre por região"
Bot:  [Drill-down query] [Heat map of Brazil by state]
```

## ✨ Capabilities
- **Drill-down**: automatically explores dimensions when prompted
- **Insight narration**: explains data in business language
- **Anomaly alerts**: proactively surfaces unusual patterns
- **Export**: PDF reports, Excel, scheduled email digests
